# CHECK DE PRONTIDÃO DO STARTER

O starter está correto quando:
- a instalação das dependências conclui sem erro;
- `npm run dev` inicia a aplicação;
- a tela identifica corretamente o sistema;
- `npm run build` conclui sem erro;
- nenhuma funcionalidade de negócio do PRD está pronta antecipadamente.

## Regra pedagógica
Starter = ambiente técnico.
Golden Master = solução de referência do instrutor.
Eles não podem ser confundidos.
