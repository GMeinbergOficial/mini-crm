# Starter — Mini CRM

Este é o **ambiente inicial**, não a solução final.

## O que já existe
- React + TypeScript + Vite
- estrutura mínima de `src/`
- tela neutra de confirmação do ambiente
- scripts `dev`, `build` e `preview`

## O que NÃO existe
- CRUD funcional
- regras de negócio do PRD
- persistência
- filtros
- solução visual final
- Golden Master

## Antes de construir
1. Leia `../README.md`.
2. Leia `../PRD.md`.
3. Leia `../CLAUDE.md`.
4. Trabalhe somente no checkpoint indicado pelo instrutor.
5. Não implemente o sistema inteiro em uma única solicitação.

## Instalação
Use a versão de Node/runtime oficialmente congelada para o workshop.

```bash
npm install
npm run dev
```

Antes de considerar um checkpoint concluído:

```bash
npm run build
```

> Se a instalação não funcionar, não troque dependências aleatoriamente. Registre o erro real e siga o protocolo do instrutor.
